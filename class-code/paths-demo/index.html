Demonstrating Image Paths

1. Image in the Same Folder (Relative Path)

This image is located in the same folder as this HTML file.

Code: <img src="local-image.png" alt="Local Logo">

2. Image on the Desktop (Absolute Path)

This image is located on your Mac's Desktop.

Code: <img src="/Users/codefinite/Desktop/desktop-image.png" alt="Desktop Logo">

💡 Why is this image broken?
If you see a broken image icon here, your browser is doing its job! Modern browsers (like Chrome) and tools (like Live Server) strictly block websites from reading files on your Desktop or other personal folders for security reasons.

To see it actually load, you have to open this HTML file directly in Safari or Firefox by double-clicking it in Finder, which may ask for permission to access your Desktop folder.
