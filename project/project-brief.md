# Lab and Homework: The College Website

**Lecture 03** · HTML only

## What you are building

A four-page college website that shares one navigation menu.

```
college-site/
├── index.html
├── about.html
├── courses.html
├── contact.html
└── images/
```

## Lab (in class)

| Page | Must include |
|---|---|
| `index.html` | `h1` with the college name, a welcome paragraph, the logo with alt text |
| `about.html` | A short history and at least one photo with good alt text |
| `courses.html` | A course list (the table comes in the homework) |
| `contact.html` | Address, phone and an email link |
| Every page | The same `nav`, and every link works |

Test every link: 4 pages × 4 links = **16 clicks**.

## Homework (due before Lecture 04)

- [ ] A course table in `courses.html`
- [ ] A `caption` and `th` header cells
- [ ] At least four courses as rows
- [ ] The same nav working from every page
- [ ] Alt text on every image
- [ ] Lowercase file names, no spaces

## Submit

`college-site/` folder (zipped) · a path explanation: for two of your images, write the path you used and which folder it resolves to
